# Weight on Different Planets Comparator

Enter your Earth weight in kg or lbs and instantly see your equivalent weight on all 10 solar system bodies with a horizontal bar chart and fun facts.

## Features
- Weight input with kg/lbs toggle that converts values automatically
- 10 bodies: Mercury, Venus, Earth, Moon, Mars, Jupiter, Saturn, Uranus, Neptune, Pluto
- Planet cards showing weight, emoji, and percentage difference from Earth
- Chart.js horizontal bar chart comparing all bodies at a glance
- Fun facts panel with contextual commentary for each body

## Usage
Type your weight in the input field and toggle between kg and lbs. The planet cards and chart update instantly. Scroll down to read the fun facts panel for context on each result.
